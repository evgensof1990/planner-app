# Плановик

Планировщик дел в стиле TickTick: задачи, планы на неделю, проекты с секциями и канбаном, теги, привычки, календарь, помодоро-таймер. Тёмная тема, фиолетовый акцент.

Одна кодовая база на React + Vite, Android-сборка через Capacitor. Данные хранятся на устройстве и синхронизируются между устройствами через приватный GitHub Gist (Настройки → Синхронизация, нужен токен с доступом gist).

Веб-версия: https://app.myrenthub.ru/

## Запуск на компьютере

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статическая сборка в dist/
npm run build:single  # один самодостаточный файл dist-single/index.html
```

## Android

APK собирается автоматически GitHub Actions при каждом пуше в `main`: смотрите раздел Releases или ветку `builds`.

Локально (нужен Android Studio / SDK):

```bash
npm run android
cd android && ./gradlew assembleRelease
```

## Свой сервер (Яндекс.Календарь)

Папка `server/` — небольшой сервер без зависимостей (Node.js 18+): хранит данные плановика вместо Gist и двусторонне синхронизирует задачи с Яндекс.Календарём по CalDAV.

- Задачи с датой и временем попадают в календари «Плановик Работа» и «Плановик Личное» (их нужно один раз создать в Яндекс.Календаре). Рабочими считаются задачи проектов, в названии которых есть «работ».
- Если перенести или удалить такое событие в Яндекс.Календаре, задача в плановике обновится.
- События остальных календарей (включая повторяющиеся) приложение показывает как занятость.

Установка на сервере с nginx: `git clone` репозитория, затем `sudo bash deploy/install.sh`. Скрипт спросит логин и пароль приложения Яндекса и выдаст ключ доступа для приложения. Тесты: `npm test`.

## Telegram-бот и голос

Сервер не ходит в Telegram сам: между ними стоит Cloudflare Worker (`deploy/telegram-worker.js`).
Он получает сообщения бота, пересылает их на сервер и выполняет ответы, а раз в минуту забирает
с сервера утренний план и напоминание об обзоре недели.

1. На сервере: `sudo bash deploy/setup-telegram.sh`. Скрипт добавит `TG_RELAY_SECRET` в `/etc/planovik.env`
   и спросит API-ключ SpeechKit для распознавания голоса (можно пропустить).
2. В Cloudflare: Workers → Create → вставить код `deploy/telegram-worker.js` → Deploy.
   Переменные: `BOT_TOKEN` (от @BotFather), `RELAY_SECRET` (из шага 1), `SERVER_URL=https://plan.myrenthub.ru`.
   Триггер Cron `* * * * *`.
3. Открыть `https://<воркер>.workers.dev/setup?secret=<RELAY_SECRET>`.
4. В приложении: Настройки → Синхронизация → «Привязать Telegram» и отправить боту `/start КОД`.

Переменные сервера: `TG_RELAY_SECRET`, `SPEECHKIT_API_KEY`, `DIGEST_TIME` (по умолчанию `08:30`).
